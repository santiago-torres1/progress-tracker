# Goal catalogue

The starting sets a new visitor picks from, six per life area. Approved 2026-09-17 as a starting
point — expect to edit them as the app is used. This file is the source of truth: change it here,
then change the reference data to match in the same pull request.

## Rules that apply to every template

1. **A template is a starting point, never a fixed contract.** Whatever a template suggests, the
   person can change the target, the minimum, the unit and the title — both while adding the goal
   and at any time afterwards. A template that cannot be edited is a worse version of a text field.
2. **Every area ends with "Something else".** A custom goal is always available, in every category,
   and reaches the same editor with nothing pre-filled.
3. **Habit minimums ship well below their target**, so a new goal encourages from day one. That is
   the product's core rule expressed as data (see `CLAUDE.md`).
4. Titles are second-person and deliberately unspecific — the person makes them concrete. Revisit
   this if the picker ever feels vague rather than inviting.
